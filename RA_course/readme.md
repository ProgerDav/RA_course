# Russian Art History Course

## Structure

Course structure should follow the following pattern:

```
RA_course/
├── lectures.tex
├── references.bib
└── lectures/
    ├── 01-introduction/
    │   ├── lecture.tex
    │   └── images/
    └── 02-medieval-art/
        ├── lecture.tex
        └── images/
```

All lectures will be compiled into a single PDF file, while sources for each lecture will be stored in a separate directory.
